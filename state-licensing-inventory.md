# US Food-Establishment Licensing & Inspection Data Inventory

**Project:** neutral eats — authoritative license/inspection data as a venue STATUS layer (the model: Florida DBPR data powered the original Florida version).
**Compiled:** 2026-10-26, from six regional research passes. Research only — no datasets were downloaded and no records requests were filed.
**Verification key:** "Verified" = the URL was fetched during this research pass. Anything marked **UNVERIFIED** comes from search results, catalogs, or secondary sources and was not directly confirmed — treat accordingly. Cadence is stated only where the source states it.

## Headline findings

- **There is no national feed.** Retail food licensing/inspection is state- or local-run everywhere; the US splits roughly into (a) a handful of centralized states with real bulk data, (b) states with a per-record lookup portal only, and (c) fully fragmented states where counties/cities hold everything.
- **Florida DBPR is the outlier gold standard** — the only statewide source found that combines free weekly bulk files with license status codes, license expiry dates, last inspection dates, and inspection dispositions in one schema.
- **True license-status fields are rare.** Most "open data" in this space is inspection history (date/score/violations). Closure usually has to be inferred from an inspection result ("Out of Business", grade "Closed", a red placard), not read off a license registry.
- **The best machine-readable sources are metros, not states:** NYC, Boston, Chicago, King County (Seattle), Clark County NV (Las Vegas), San Francisco, Austin, Louisville, Baton Rouge, Detroit.
- **Watch for platform churn:** Iowa moved to SAFHER on 2026-10-20 (pre/post split), Kansas changed platforms 2026-07-06, South Carolina's program moved from DHEC to the Dept. of Agriculture on 2024-07-01 (legacy DHEC URLs still resolve), San Francisco's portal domain migrates data.sfgov.org → data.sf.gov by 2026-11-20, and LA County made full inspection reports CPRA-request-only for inspections on/after 2025-08-25.

## Tier 1 pilot shortlist — bulk/API **with** a usable status signal

Ranked by approximate venue population covered (figures are rough estimates from program sizes, marked ~).

| # | Source | ~Venues | Access | Status signal | Cadence | Format quirk (one line) |
|---|---|---|---|---|---|---|
| 1 | **Florida — DBPR Div. of Hotels & Restaurants** | ~50,000 | Bulk download (free ASCII/CSV-like) | Primary + secondary license status codes, **expiry date**, last inspection date, inspection disposition, violation counts | Weekly | Combined hotel + restaurant schema — lodging columns sit empty for restaurants; license-type codes (2010/2013/2014…) separate them; DOH-licensed institutional venues (schools, hospitals, bars w/ limited food) are NOT in DBPR — separate county lane, no bulk file |
| 2 | **New York State — Health Data NY (excl. NYC, Suffolk, Erie)** | ~45,000 | Socrata API + bulk | Active vs inactive (closed) published as **separate datasets** = implicit status; last inspection date | Monthly | Union the active + inactive datasets to get status; NYC/Suffolk/Erie run their own systems and are absent |
| 3 | **New York City — NYC Open Data (DOHMH)** | ~27,000 | Socrata API + bulk CSV/JSON/GeoJSON | ACTION field incl. closed-by-DOHMH / reopening; grades A/B/C/Z/P; dataset holds active establishments only | Near-daily | One row per violation citation (establishment fields repeat); inspection date 1/1/1900 = permitted, not yet inspected |
| 4 | **Chicago — City of Chicago Data Portal** | ~15,000 | Socrata API + bulk | Inspection `results` incl. **Out of Business** (closure proxy), license #, inspection date | Near-daily | "Out of Business" is an inspection result, not a license revocation — it can also fire on operator change (old record closes, new one opens); no expiry date |
| 5 | **King County, WA — data.kingcounty.gov** | ~13,000 | Socrata API + bulk (dataset `r878-4sxa`) | **`inspection_closed_business` Yes/No flag**, inspection result/score, grade | Not stated (data current at fetch) | One row per violation — dedupe on `Inspection_Serial_Num`; an older 2006–present dataset (`f29f-zza5`) also exists — do not mix the two |
| 6 | **Clark County, NV — Southern Nevada Health District** | ~8,000 | Bulk zip download (CSV + `restaurants.sql` DDL) | Grade A/B/C/**Closed** (closure is a grade value), demerits, inspection date, permit # | **Nightly** | Full inspection *reports* are still a records request — the download is scores/grades only; Washoe Co. (Reno) is a separate lookup-only system |
| 7 | **Boston — Analyze Boston (CKAN)** | ~3,200 | CKAN bulk CSV + Data API | **`licstatus` field**, inspection result codes incl. **HE_VolClos** (voluntary closure), license # | Daily | Two datasets: inspections + a companion "Active Food Establishment Licenses" file — join on license number; presence in the companion file = currently licensed. Smallest Tier 1 source, cleanest license-status semantics |

**First pilot recommendation:** FL DBPR (already the project's home turf and the richest status schema) → NYC + NY State (one Socrata pattern covers ~72k venues) → King County (only explicit closed-business flag in an API) → Boston (only true license-status field in an API). Chicago and SNHD round out the same patterns.

## Tier 2 — machine-readable but no true status field, or strong status but not machine-readable

Worth knowing about, not pilot-ready as a status layer:

- **San Francisco (DataSF Socrata)** — excellent inspection API, but zero license status/expiry/closure fields. Status would have to be inferred from inspection recency.
- **Delaware (Socrata)** — statewide and machine-readable, but it is a *violations* file, not a registry: no status, no expiry, no closures.
- **Louisville, KY (ArcGIS)** — bulk + API + daily, but inspection scores only; no status/expiry.
- **Austin, TX (Socrata)** — bi-weekly scores; no status fields; 3-year window only.
- **Baton Rouge, LA (Socrata)** — the only machine-readable feed in Louisiana; parish-scoped; Permit ID but no status.
- **Detroit, MI** — monthly open data, compliant/not-compliant only.
- **Houston, TX (CKAN)** — XLSX + API including a "Last Facility Inspection" dataset; no verified status/expiry.
- **San Diego Co., CA** — permitted-facilities download is implicitly "currently operating," and closures live in the lookup, not the bulk file.
- **Kansas (state portal)** — the strongest non-bulk signal found: filterable compliance status, refreshed nightly. But it is a search portal, not a documented bulk/API feed — at-scale use means portal scraping or a records request. ⚠️ K.S.A. 45-230 restricts certain commercial uses of names/addresses obtained from KS public records (up to $500/violation) — legal review before commercial reuse.
- **Mississippi (state lookup)** — per-record **Permit Date + Expire Date + Status: Open**; only FL beats it for status semantics, but there is no bulk route — a "Data Export" label in the UI is UNVERIFIED as a public export.
- **Hawaii (state lookup)** — Red placard = closed is a first-class status, lookup-only; the only download (Oahu permit list) is stale (Jan 2020) and carries no status.
- **Colorado CDPHE (lookup)** — inspection outcome literally includes "Closed," but only via the per-record portal and only for CDPHE + data-sharing counties.
- **Pierce Co., WA / Sacramento Co., CA / Santa Clara Co., CA (lookups)** — all publish closure/placard signals (Closed rating, Red placard) with no bulk route.

## Hard cases — no usable machine-readable route found

- **West Virginia** — the worst case: permitting/inspection is explicitly county-only, the state does not routinely inspect, and there is no statewide portal, field, or feed of any kind. Coverage = 50+ separate county sources.
- **Massachusetts (outside Boston)** — 351 local boards of health, no state data system. Boston is a Tier 1 exception, not a pattern.
- **Connecticut** — 59 local health jurisdictions, state is oversight/training only, no statewide dataset.
- **New Jersey** — county/municipal licensing; no statewide portal; OPRA requests are the fallback.
- **Missouri** — 115 independent Local Public Health Agencies; the state issues no retail food license at all.
- **Nebraska** — no public inspection/license search or bulk file found on the state agriculture site; effectively records-request only.
- **Minnesota** — inspection reports are public but obtained by contacting the licensing authority; no statewide online search or bulk. Split MDH/MDA jurisdiction means two sources per venue.
- **Utah** — 13 local health districts, no unified portal; district-by-district integrations.
- **Montana** — state licenses but counties inspect; no DPHHS dataset found; county PDFs at best.
- **Indiana / Ohio** — county/district licensors (95 / 124 of them); lookups exist only where a locality built one.
- **Texas / California / Washington (state level)** — no state feed exists; only the metro/county sources in the addendum are usable. In CA that's up to 62 separate agencies for full coverage.
- **New Mexico** — no verified public search or feed; IPRA request is the route (Albuquerque runs its own program with a weekly red/green report).
- **Oklahoma** — a lookup exists per secondary sources but its fields could not be verified in this pass; treat as unknown until re-checked.

## Method & caveats

- Compiled 2026-10-26 from six parallel regional passes; each URL was fetched unless marked UNVERIFIED. Several government portals rate-limited fetches (HTTP 429/403) — those rows say so.
- "Lookup only" portals (many run on shared platforms — MyHealthDepartment, HealthSpace, EnvisionConnect, Accela) have no documented public API; using them at scale means scraping per-record results or negotiating a bulk extract via public-records request, which this inventory deliberately did not do.
- Venue-population figures in Tier 1 are order-of-magnitude estimates from program scale, not counts pulled from the datasets (no datasets were downloaded, per scope).
- Inspection data ≠ license data: several states publish one without the other (e.g. Delaware = violations only; Wyoming publishes routine inspections only and *excludes* follow-ups, so its feed structurally cannot show a closure).
- License expiry, where it exists, usually lives in the licensing system, not the inspection system — FL DBPR and MS are the exceptions that expose it publicly.
