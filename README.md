# Neutral Eats

**Restaurants near you, instead of restaurants promoted near you.**
No ads. No bias. Just food.

Neutral Eats is an unbiased nearby-restaurant finder: results are ranked by
distance and data quality only. No venue can pay for placement, and no
sponsored input exists anywhere in the pipeline.

- Live: https://neutraleats.com
- Status: revival in progress (Oct 2026) — see `RESCUE.md` for the rescued
  state and the Overture Maps data-rebuild plan.
